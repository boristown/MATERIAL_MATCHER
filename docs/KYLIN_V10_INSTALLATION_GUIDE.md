# 银河麒麟 V10 安装说明（普通用户）

适用于已经由运维人员准备好的“物料集团码智能匹配平台”安装介质。普通用户不需要执行 Python、Node、Docker 或数据库命令。

1. 双击 **安装物料集团码智能匹配平台.desktop**；如果桌面环境不允许直接运行，就双击/运行 **启动安装.sh**。
2. 在欢迎页点击下一步；安装向导会自动检查银河麒麟、Python 3、systemd 和安装介质完整性。
3. 选择安装路径。没有特殊要求时保持默认路径即可。
4. 确认访问端口。没有端口冲突时保持默认 `18080` 即可；“数据路径”只在高级场景下修改。
5. 输入 admin 初始密码，或者留空让系统自动生成，然后确认开始安装。
6. 等待安装完成。升级时安装器会保留已有账号、数据库、索引和结果；失败时会尝试恢复旧版本。
7. 安装完成后，**记录并妥善保存 admin 密码**。
8. 用浏览器打开向导显示的访问地址，登录系统。

> 本仓库提供安装向导和构建源码。Python Runtime、Node Runtime、Docker image tar、离线 RPM 与最终大型离线安装介质由后续 OpenCode 构建/部署流程准备，本说明不表示这些大型产物已经生成。
