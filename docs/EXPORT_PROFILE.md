# Excel 导出模板（Export Profile）

最终 Excel 的业务数据与工作簿展现已经分层。默认不配置时，系统继续使用与原版本完全一致的“标准业务结果”样式。

## 配置位置

运行环境可选配置：

```text
/etc/material_matcher/export_profile.json
```

实际目录由 `MATERIAL_MATCHER_CONFIG_DIR` 决定。仓库提供完整示例：

```text
config/examples/export_profile.json
```

将示例复制到配置目录后即可调整。当前服务在启动时加载模板，因此修改配置后需要重启后端服务；不需要重新编译 Python 源码，也不需要重新制作安装介质。

如果配置文件不存在，系统使用内置标准模板。如果配置文件损坏或存在非法值，系统发出 RuntimeWarning 并安全回退到内置模板，避免影响结果导出。

## 当前可调整项

- Excel 文件名前缀
- TopN 候选输出数量
- 5 个 Sheet 的名称
- 分区标题
- 系统生成字段的表头名称
- 摘要页业务文案
- 匹配状态、匹配方式、人工操作的显示名称
- 表头/分区/状态/字段比对颜色
- 日期时间格式
- 冻结窗格
- 分组表头行高
- 普通表头行高
- 最大自动列宽
- 摘要页 A~D 列宽

源 Excel 与集团目标 Excel 的业务字段仍然按真实任务 payload 动态展开，因此不会因为某个客户模板字段变化而写死列结构。

## 向后兼容

默认 Export Profile 完整复制当前生产 Excel 契约：

- Sheet：匹配摘要、最终匹配结果、Top5候选、人工操作记录、未匹配清单
- 分区、字段顺序、颜色、冻结、筛选、列宽逻辑不变
- TopN 默认仍为 5
- 原有状态文案和人工操作文案不变

现有 Excel 回归测试继续以原样式为验收基线。

## 安全边界

Export Profile 只控制 Excel 展现，不修改：

- 匹配结果数据
- 匹配状态
- 人工审核结果
- 候选排序
- 相似度计算
- 历史任务

未知配置键、重复 Sheet 名、超过 31 字符的 Sheet 名、非法颜色、非法 TopN 都会被拒绝，并在非 strict 模式下回退到标准模板。

## 后续扩展

这一层可以继续承载：

- 导出模板管理 UI
- 不同客户/方案选择不同 Export Profile
- 业务字段显示/隐藏
- 业务字段别名与排序
- 多套模板版本管理

这些扩展不需要再改变匹配结果数据模型。
