# 13 所物料类别业务配置说明

> 本文仅描述 13 所首个落地场景的业务配置，不属于底层引擎固定逻辑。

## 1. 当前公开样例中的物料类别

13 所公开 SAP 样例中出现以下类别：

| SAP 类型代码 | 一层分类描述 | 当前集团码样例 |
|---|---|---|
| A001 | 元器件 | 元器件集团码表 |
| A002 | 标准件 | 标准紧固件集团码表 |
| A003 | 金属材料 | 金属材料集团码表 |
| A005 | 非金属材料 | 非金属材料集团码表 |
| A006 | 复合材料 | 复合材料集团码表 |
| A007 | 物资类其他 | 当前公开包中未提供独立同名集团码表 |

这些类别不是系统固定枚举。后续其他所可以使用完全不同的类别代码和类别名称。

## 2. 配置原则

每个类别可以独立配置：

- 使用哪一套集团码数据；
- 参与匹配的字段；
- 字段一对一、一对多、多对一、多对多关系；
- 字段拼接顺序；
- 字段匹配方式；
- 字段权重；
- 同义词与清洗规则；
- 分类映射方式；
- 匹配成功阈值；
- 人工复核阈值；
- 相似度显示系数；
- 前 N 名候选数量。

底层程序只负责执行这些通用能力，不判断“某一类别应该用哪些固定字段”。

## 3. 当前建议的业务关注字段

### A001 元器件

可重点关注：分类层级、名称、型号、详细型号/规格、质量等级、封装形式、生产厂家、规范/标准、外形尺寸等。

### A002 标准件

可重点关注：名称、规格尺寸、材料、表面处理、标准号、机械性能等。

### A003 金属材料

可重点关注：牌号、规格、材料形态、采用标准、生产厂家、国产/进口等。

### A005 非金属材料

可重点关注：名称、型号/牌号、规格、采用标准、生产厂家及材料属性等。

### A006 复合材料

可重点关注：名称、牌号、规格、采用标准、生产厂家、状态等。

### A007 物资类其他

不预设固定字段。应根据实际业务再配置目标集团码范围和字段规则，可选择独立目录、多个目录或全局匹配。

## 4. 运行时选择关系

```text
13 所客户物料
    ↓
读取物料类型
    ├─ A001 → 元器件业务方案
    ├─ A002 → 标准件业务方案
    ├─ A003 → 金属材料业务方案
    ├─ A005 → 非金属材料业务方案
    ├─ A006 → 复合材料业务方案
    └─ A007 → 物资类其他业务方案
```

这一选择关系本身也由配置维护。另一个客户即使使用 Z001、Z006 或完全不同的编码，也无需修改底层程序。

## 5. 与底层引擎的边界

底层引擎不得出现以下形式的客户专用逻辑：

```text
如果客户是 13 所，则……
如果物料类型是 A001，则写死某几个字段……
如果物料类型是 A006，则使用固定权重……
```

正确方式是：

```text
读取客户业务配置
    ↓
根据配置选择目标数据和匹配方案
    ↓
调用统一匹配能力
```

因此，13 所仅提供第一套可验证的业务配置模板，不改变物料集团码匹配引擎的通用底座。
