## 一、需要开通的端口清单（白名单方向：客户端 → 服务器）

| 方向 | 协议/端口 | 用途 | 必要性 |
|---|---|---|---|
| 客户办公网终端（含 Windows 7 PC）→ 服务器 IP | TCP **18080** | MATERIAL_MATCHER Web 服务（登录、四步业务、结果下载） | 必开 |
| 运维跳板机 → 服务器 IP | TCP 22（客户现有 SSH 管理通道） | 安装与维护（按客户既有管理规范） | 已有 |

说明：

1. **默认端口 18080**。安装向导允许改选（如 18081）；最终生效端口以安装成功页面与 `/var/log/material_matcher/install-reports/` 安装报告为准。开墙时请按实际安装端口。
2. 服务器**无需任何对外访问**：安装全程离线（Docker Engine、Compose、应用镜像、依赖、模型、业务种子数据全部随介质提供），系统运行期间不访问公网、不回连任何外部服务。**出站方向不需要开通任何白名单。**
3. Docker 守护进程仅使用本地 Unix Socket（`/run/docker.sock`），**不开启 2375/2376 TCP 管理端口**；容器端口映射仅 `0.0.0.0:18080→18080` 一条，无其它监听端口。
4. 安装器不修改防火墙规则。若服务器启用了 firewalld/安全加固，请客户网络管理员在服务器本机放行 TCP 18080（例如 `firewall-cmd --add-port=18080/tcp --permanent && firewall-cmd --reload`），内网边界设备按上表做定向白名单。
5. 如客户侧后续加挂反向代理，仅需保证“代理 → 服务器:18080”可达，代理对外端口由客户自行规划。
6. 单服务器部署，无数据库/缓存等其它中间件端口需求（SQLite/索引均为本地文件，无网络监听）。
