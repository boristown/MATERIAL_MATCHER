# 物料集团码匹配引擎操作界面设计

> 文档版本：1.0  
> 日期：2026-09-12  
> 目标：把业务操作流程固化为可直接指导前端实现和验收的界面设计，避免开发阶段只实现底层配置能力、但业务人员难以使用。

## 1. 设计原则

系统采用 B/S 架构，推荐使用 Vue 3 构建现代化中文管理界面。普通业务人员不需要理解配置文件、插件、索引参数或底层算法名称。

界面遵循以下原则：

- 业务术语优先，普通模式尽量不出现技术缩写；
- 参数尽量使用数字表达，避免“低、中、高、很高”等主观等级；
- 字段权重统一使用 `0～100` 数字；
- 匹配成功阈值、人工复核阈值统一使用 `0～100` 分；
- 配置过程采用向导，系统自动识别并给出推荐值，用户以确认和调整为主；
- 任何重要配置发布前必须能够小批量试跑；
- 试跑结果应实时帮助用户理解权重和阈值变化带来的业务影响；
- 长任务、索引构建、批量匹配不能因为浏览器刷新而丢失；
- 删除、回滚、清理等危险操作必须二次确认。

## 2. 总体页面布局

建议采用“左侧固定导航 + 顶部状态栏 + 中间工作区”：

```text
┌──────────────────────────────────────────────────────────────┐
│ 物料集团码匹配引擎                当前方案：13所-元器件  admin │
├──────────────┬───────────────────────────────────────────────┤
│ 首页         │                                               │
│ 匹配任务     │                 当前页面工作区                │
│ 配置方案     │                                               │
│ 集团码数据   │                                               │
│ 字典管理     │                                               │
│ 临时文件     │                                               │
│ 系统管理     │                                               │
└──────────────┴───────────────────────────────────────────────┘
```

左侧导航位置保持稳定。顶部显示当前业务方案、任务/服务状态和管理员入口。

## 3. 首页

首页只展示业务入口和状态概览，不堆叠复杂参数。

建议包含：

- “新建匹配任务”主按钮；
- “新建匹配方案”主按钮；
- 最近任务及其状态；
- 已发布匹配方案数量；
- 集团码数据版本及索引状态；
- 待人工复核数量；
- 临时文件占用空间；
- 数据磁盘剩余空间。

## 4. 新建匹配方案向导

顶部固定步骤条：

```text
① 客户物料 → ② 集团码数据 → ③ 分类范围 → ④ 字段对应
        → ⑤ 权重与阈值 → ⑥ 试跑验证 → ⑦ 发布方案
```

每一步均提供：

- 上一步；
- 保存草稿；
- 下一步。

配置草稿应自动保存，避免长时间配置过程中内容丢失。

## 5. 客户物料与集团码数据页面

用户上传文件后，系统自动识别并展示：

- 文件名、文件大小、记录数；
- 推荐工作表；
- 推荐表头行；
- 字段列表；
- 每个字段的样例值；
- 前导零风险；
- 空值/特殊占位符风险；
- 重复值风险。

用户可以直接修改工作表和表头行，页面立即刷新预览，无需重新上传。

集团码数据既可以上传新文件，也可以选择已经维护并建立索引的数据版本。

## 6. 分类范围页面

该页面用于配置“某类客户物料应该到哪些集团码数据范围中匹配”。

支持：

- 同组严格匹配；
- 指定多个集团分类；
- 不区分物料组的全局匹配；
- 一个客户物料组映射多个集团分类；
- 不同物料类别选择不同集团码数据版本和匹配方案。

所有分类代码属于业务配置，不进入底层固定枚举。

## 7. 字段对应页面

这是配置核心，采用表格化编辑：

```text
客户字段                 集团字段                 匹配方式       权重值   关键字段
──────────────────────────────────────────────────────────────────────
物料名称          ↔      产品名称                 相似匹配         50      □
型号 + 规格       ↔      详细型号                 综合匹配        100      ☑
生产厂家          ↔      生产厂家                 清洗后比较       60      □
技术标准          ↔      采用标准                 标准号比较       80      ☑
```

交互要求：

- 客户字段、集团字段通过下拉框选择；
- 点击“+”可形成一对多、多对一或多对多字段组合；
- 支持拖动字段调整拼接顺序；
- 匹配方式使用中文名称；
- 权重使用 `0～100` 数字输入框，并提供联动滑块；
- 权重变化后实时显示归一化占比；
- 支持关键字段开关；
- 支持新增、复制、删除字段关系。

## 8. 权重与阈值页面

普通用户不再使用“低、中、高、很高”。所有重要程度都使用数字。

示例：

```text
字段权重
型号/牌号       [100]  ━━━━━━━━━━━━━━━━━━━━  25.0%
规格            [100]  ━━━━━━━━━━━━━━━━━━━━  25.0%
技术标准         [ 80]  ━━━━━━━━━━━━━━━━      20.0%
生产厂家         [ 60]  ━━━━━━━━━━━━          15.0%
名称            [ 50]  ━━━━━━━━━━            12.5%
备注            [ 10]  ━━                     2.5%

判定阈值
自动匹配成功：   [88] 分以上
进入人工复核：   [75]～[88] 分
低于 75 分：     未匹配
```

规则：

- 权重值范围 `0～100`；
- `0` 表示不参与评分；
- 权重值不要求合计为 100；
- 系统自动归一化并显示实际占比；
- 成功阈值和复核阈值使用 `0～100` 分显示；
- 后端内部允许使用 `0～1` 浮点值，但普通用户不接触。

页面右侧显示最近一次试跑影响，例如：

```text
预计自动匹配：62%
预计人工复核：21%
预计未匹配：17%
```

业务人员调整权重或阈值后，可以直接重新试算，看到参数变化对结果分布的影响。

## 9. 同义词与分类映射页面

同义词使用“标准写法 + 其他写法”的表格：

```text
标准写法          其他写法
生产厂家甲        厂家甲、甲公司、甲厂
不锈钢            SUS、不锈、Stainless Steel
```

支持按客户、物料类别、字段维护同义词。

分类映射采用左右两栏选择：左侧客户物料组，右侧允许匹配的一个或多个集团分类，并支持搜索、批量勾选和复制已有映射。

## 10. 试跑验证页面

方案发布前必须完成试跑。

页面顶部显示：

- 试跑物料数；
- 自动匹配率；
- 人工复核率；
- 未匹配率。

结果表显示：

- 客户物料号；
- 客户物料描述；
- 第一候选集团码；
- 相似度；
- 判定状态。

点击某条记录后打开右侧详情抽屉，显示前 N 名候选、各字段得分、关键命中和关键冲突，方便判断当前权重和阈值是否合理。

## 11. 匹配任务页面

任务采用列表管理：

```text
任务名称   使用方案   数据量   状态      进度     开始时间   操作
9月批量01  元器件v3  52310   运行中    68%      10:23     查看
9月批量02  复合材料v2 8200   已完成    100%     09:05     下载
```

状态至少包括：

- 等待执行；
- 运行中；
- 已完成；
- 失败；
- 已取消。

运行中显示进度和预计剩余时间；失败任务显示业务人员可以理解的错误原因。

## 12. 结果查看与人工复核页面

结果页使用三个标签：

- 已匹配；
- 待复核；
- 未匹配。

表格直接显示集团码和相似度。用户可查看前 N 名候选和字段级得分。

待复核记录允许用户选择某个候选并点击“人工确认”。人工确认结果应保存为后续评测和权重优化样本。

## 13. 集团码数据与索引页面

显示：

- 当前集团码数据版本；
- 数据记录数；
- 最近更新时间；
- 索引是否可用；
- 索引构建进度；
- 索引占用空间。

提供：

- 上传新版数据；
- 构建/更新索引；
- 回退上一版。

单比特向量等底层参数只在高级模式显示，普通业务模式只显示状态、进度和结果。

## 14. 临时文件页面

按任务显示临时文件：

- 文件/任务名称；
- 占用空间；
- 创建时间；
- 当前是否正在使用；
- 是否允许安全清理。

支持清理单个任务、指定天数以前文件和全部安全可删除文件。正式配置、集团码主数据、正式索引和正式结果不得进入临时清理范围。

## 15. 系统管理页面

显示：

- 服务运行状态；
- 当前版本；
- 服务端口；
- 数据目录；
- 数据磁盘总空间及剩余空间；
- 最近错误信息；
- 向量索引状态。

普通用户不需要看到 Linux 命令。提供“复制诊断信息”按钮，便于实施人员远程排查。

系统固定使用 `admin` 管理员账号。安装时自动生成随机 10 位密码，密码保存在：

```text
/etc/material_matcher/secret/admin_password.env
```

## 16. 前端实现与验收约束

- 使用 Vue 3 + TypeScript 实现；
- 普通业务操作全部采用中文；
- 核心操作按钮位置稳定；
- 支持至少 1366×768 分辨率下正常操作；
- 表格字段过多时固定关键列并允许横向滚动；
- 配置草稿自动保存；
- 浏览器刷新后长任务状态能够恢复；
- 上传、索引构建、匹配任务均展示实时状态；
- 危险操作必须二次确认；
- 普通模式不暴露底层配置文件和技术参数；
- 前端生成的所有业务配置必须通过统一配置模型提交给同一匹配引擎，禁止在前端写客户专属判断。

## 17. UI 验收场景

至少使用三套不同客户数据验证：

1. 单表客户：完成上传、字段映射、数字权重、试跑、发布和正式匹配；
2. 多表客户：通过补充数据关联后完成同样流程；
3. 多物料类别客户：不同类别分别路由不同集团码数据和规则，但使用同一套 UI 和同一套程序。

验收要求：三套场景都不需要修改 Vue 或后端核心代码，只变更业务配置。
