# 1.3.21 真压测报告（2026-09-24 深夜，客户测试床=13 所孪生环境）

场景：40,000 SAP 行 × 900,000 集团码行，真实 BGE-base ONNX（vector+ANN），测试床限 20 核（13 所现场 128 核）。
全程每 0.4-0.5s 轮询探针（health/profiles/progress 各 9306 样本）测响应性。原始日志：.scratch/perf1321/{stress,w2,w3}-testbed.log

| 指标 | 测试床实测(20核/4workers) | 13 所 128 核外推 |
|---|---|---|
| 90万行上传 | 92.0s | ~40-60s（磁盘主导） |
| 目录构建（缓存命中） | 0.0s | 0 |
| 开始匹配 POST | 0.02s（FREEZING→2s→RUNNING） | 同 |
| 冷跑 INDEX（90万向量化） | ~68min @12.8k行/min | ~15-25min（ORT 随核数扩展） |
| 冷跑 RERANK 4万查询 | ~58min @695行/min | 受 GIL 限制，次线性 |
| 冷跑合计 | ~2h48m | ~1-1.5h（一次性） |
| **热跑合计（跳过 INDEX）** | **88min（含 PERSIST ~30min）** | **~40-60min** |
| finalize | 0.01s 返回 → 46s 后台完成 | 同 |
| 结果下载 18.5MB | 0.1s | 同 |
| **满载时 API p95** | **119ms**（max 1.22s） | 同 |

结论：
1. 现场"4 小时"痛点（scan 回退+锁链+同步导出）在 vector+ANN 下量级改变：冷 ~1-1.5h 一次性、热 ~40-60min；**期间页面全程可用（p95 119ms 实证）**。
2. 新瓶颈=RERANK(695/min)+PERSIST(20万候选行 30min) → 立项 **#199**（1.3.22 弹药：persist 批量化、rerank 多进程/向量化、workers 自适应默认）。
3. workers 横向扩展双实例实验被容器 env 优先级阻挡（产品 compose 路径支持）；现场可先用 MATERIAL_MATCHER_MATCH_WORKERS 调参取真实曲线。
