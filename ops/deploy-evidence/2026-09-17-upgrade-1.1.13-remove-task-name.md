## 6. 保留的技术性 name 引用(必须保留的原因)

| 引用 | 保留原因 |
| --- | --- |
| `tasks.name` / `task_drafts.name` 列 | 非空历史 schema;删除需高风险 migration,且外部工具/备份兼容 |
| API 响应中的 `name` 字段 | 旧客户端兼容(已降级为 legacy 内部值 run-*,新前端不消费) |
| `profiles.name` / `catalogs.name` / `files.original_name` | 不同业务概念(方案名/数据对象名/上传原件),不在移除范围 |
| 内部生成值 `run-<id8>` | 排障可读锚点;仅存于技术列与审计 |
