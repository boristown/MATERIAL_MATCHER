# MATERIAL_MATCHER 增量升级包 → 1.3.25（一票否决修复 + 否决对照导出页）

适用起点：**1.3.20 / 1.3.21 / 1.3.22 / 1.3.23 / 1.3.24**（预检硬门，其余版本请用完整介质）

## 本版修复与新增

**① 一票否决致命缺陷修复（现场 96% 归零事故根因）**
智能匹配（语义）规则的得分是**整条召回文本的全局相似度**，并非该字段的独立相似度；
对语义规则套用否决阈值会把名称/规格等其它字段的正常差异一并计入 → 大面积误杀。
- 执行期：语义规则**忽略**否决阈值（升级后重跑任务，归零现象即消失）
- 保存期：语义规则 + 一票否决的组合**直接拒绝保存**（422 明确提示改用精确匹配）
- 界面：语义规则的"一票否决"开关置灰并给出提示；把匹配方式从智能匹配切走时会自动清除已设的否决

**② 新增导出页「否决对照」（客户需求）**
方案中启用了否决规则时，正式结果 Excel 增加一个 sheet，**同时保留否决前与否决后的中间结果**：
| 列 | 说明 |
|---|---|
| 源表原始行号 / 源数据标识 | 定位行 |
| TOP1集团码 | 该行全部候选中**否决前最优**的候选（避免并列取首条失真） |
| 否决前相似度 / 否决前应判定 | 若不启用否决，该行本会得到什么结论 |
| 否决后状态 | 实际结论（未匹配/待处理） |
| 被否决规则 / 字段比较（源 → 目标） / 否决阈值 | 是哪条规则、哪个字段、差在哪 |

页尾汇总：`被否决 N 行；若不启用该否决规则，其中 X 行将自动匹配、Y 行进入人工处理`——
用于确认否决阈值是否过严。**该页仅供对照，不改变正式结果。**

## 现场必做（重要）

1. `./upgrade.sh`（自动备份/健康三重校验；已是 1.3.25 会幂等跳过）
2. **修正原方案的质量等级规则**：把匹配方式从"智能匹配"改为**精确匹配**，一票否决阈值填 **99**

## 保障

- 预检（起点版本硬门）+ 包体 SHA 校验 + 自动备份 + 离线依赖 + 失败自动回滚；`./rollback.sh` 可回退
