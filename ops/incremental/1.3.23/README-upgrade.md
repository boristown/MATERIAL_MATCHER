## 操作（root，宿主机）

1. 校验：`sha256sum -c MATERIAL_MATCHER-incremental-1.3.20-to-1.3.23.zip.sha256`，解包。
2. `cd MATERIAL_MATCHER-incremental-1.3.20-to-1.3.23 && ./upgrade.sh`
   （自动识别 Docker/Native；可显式 `--docker 容器名` / `--native`；已是 1.3.23 时幂等跳过）
3. Docker 环境自动重启容器；若手工在容器内跑 native 模式，收尾需宿主机 `docker restart material_matcher-app`。

## 保障与判据

- 预检强制：起点版本 ∈ {1.3.20, 1.3.21, 1.3.22}；包体 SHA 校验；不满足即中止（不做任何变更）。
- 离线依赖 xlsxwriter（纯 Python）自动从 vendor/ 安装，失败在替换前中止，不留半更新。
