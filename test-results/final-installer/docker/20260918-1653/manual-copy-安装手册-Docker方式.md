# 物料集团码智能匹配平台 · 银河麒麟 V10 安装手册（Docker 方式 · 介质版）

本手册面向没有开发背景的系统管理员。全程离线，无需联网，无需你手动输入任何 Docker 命令。

> **重要：“Docker 方式”与“非 Docker 方式”是二选一的两种安装方案。**
> 按本手册安装 Docker 方式后，**不要**再执行非 Docker 方式。
> 老板/客户没有特殊要求时，推荐使用本方式。

## 你需要确认的前提

- 银河麒麟 V10 服务器（x86_64，与介质标注一致）；
- root 或 sudo 管理员权限；
- 至少 12 GB 可用磁盘空间；
- 服务器不需要预装 Docker —— 本介质自带 Docker Engine 与 Compose 的离线安装包，会自动完成安装。

## 安装步骤

1. 把整个 `01-Docker方式` 目录复制到服务器本地磁盘（不要直接从 U 盘运行）。
2. 打开终端，进入该目录并运行：

   ```bash
   cd "/你复制到的路径/01-Docker方式"
   ./启动Docker安装.sh
   ```

3. 按终端向导提示操作（每一屏都有中文说明）：
   1. 欢迎 —— 自动继续；
   2. 环境检查 —— 自动完成，逐项 ✅ 才继续；若本机已有 Docker 会提示“复用”，不会覆盖你的容器和镜像；
   3. 服务端口 —— 直接回车用 18080（占用时换端口）；
   4. 管理员密码 —— y 手工输入（≥10 位含字母数字）或 n 自动生成；
   5. 确认安装 —— 输入 y 开始；
   6. 安装进度 —— 校验介质 → 离线安装/复用 Docker Engine → 安装 Compose → 导入镜像（1～3 分钟，有持续进度）→ 生成配置 → 启动容器 → 等待就绪（有心跳提示）→ 导入 6 个正式方案与同义词 → 完成。
4. 看到【安装成功】后，在浏览器打开页面地址（局域网地址会列出；Windows 7 老旧浏览器异常时使用交付介质根目录《客户端浏览器-Win7》里的 Firefox ESR），用 admin 登录并按提示首次修改密码。
5. 安装完成后系统已自动包含：
   - 6 个正式匹配方案：A001 元器件 / A002 标准紧固件 / A003 金属材料 / A005 非金属材料 / A006 复合材料 / A007 物资类其他（跨类目）；
   - 默认同义词（写法归一化）配置及版本历史；
   - 最小验收数据在介质 `smoke/` 目录。
6. 最小验收（全部完成才算成功）：登录成功；“系统设置 · 关于”版本与 BUILD_INFO.txt 一致；能看到 6 个方案与同义词配置；用 smoke 两个文件完成一次“第一步 · 数据上传 → 第二步 · 进度监控 → 第三步 · 人工调整 → 第四步 · 输出结果”并下载结果 Excel；重启服务器后自动恢复（等待几秒至 1 分钟后重新打开页面）。

## 数据在哪里（重要）

| 内容 | 宿主机路径 |
|---|---|
| 配置/密码 | `/etc/material_matcher` |
| 业务数据（数据库、上传、结果、索引） | `/var/lib/material_matcher` |
| 日志/安装报告 | `/var/log/material_matcher` |
| Compose 项目 | `/opt/material_matcher/docker` |

容器只是运行环境：**删除或重建 MATERIAL_MATCHER 容器都不会丢失业务数据**；请勿删除上述宿主机目录。

## 安装失败时

- 向导会用中文告诉你原因（端口占用 / 介质不完整 / 磁盘不足 / 已有不兼容 Docker 等）并给出处理建议；终端各选择屏：y=第一项、n=第二项、其它键=安全退出（不做任何修改）；
- 安装报告保存在 `/var/log/material_matcher/install-reports/`；向导技术日志在 `/var/tmp/material_matcher_docker_wizard-*.log`（root 可读）；
- 技术细节保存在 `/var/tmp/material_matcher_docker_wizard-*.log`（root 可读）；
- 安装器只会创建/启动 material_matcher 自己的容器，不会删除、清理或修改你已有的任何容器、镜像、网络和数据卷。

## 维护

以 root 运行本目录 `./维护工具-Docker.sh`：查看状态、启停、日志、健康诊断、备份、验证备份、恢复、导出诊断包。

## 升级

再次运行 `./启动Docker安装.sh` 即可：自动识别升级，保留账号/密码/任务/结果；升级失败会自动回滚旧版本。
