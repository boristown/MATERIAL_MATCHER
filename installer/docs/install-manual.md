# 物料集团码智能匹配平台 · 银河麒麟 V10 安装手册

本手册面向没有开发背景的系统管理员。全程离线，无需联网。

安装介质根目录另有《README-安装前必读.txt》（一句话指引）与《BUILD_INFO.txt》（版本/commit/构建信息，用于核对）。

## 你需要准备

- 一台银河麒麟 Linux V10 服务器（x86_64 或 aarch64，与介质标注一致）；
- 管理员（root 或 sudo）权限；
- 至少 6 GB 可用磁盘空间；
- 完整复制到本地磁盘的安装介质目录（不要直接从 U 盘安装）。

## 安装步骤

1. 复制安装目录到服务器，例如 `/home/admin/物料集团码智能匹配平台安装包/`。
2. 启动安装：
   - 图形桌面：双击「安装物料集团码智能匹配平台」；若系统禁止直接运行，右键目录空白处打开终端，执行 `./启动本地安装.sh`。
   - 无图形界面：在终端执行 `./启动本地安装.sh`（旧版介质中的 `./启动安装.sh` 等效可用）。
3. 按向导提示操作。图形界面用鼠标点击对应按钮；纯终端界面请按屏幕提示输入 y 或 n（输入其它键会安全退出安装，不做任何修改）。向导依次为：
   1. 欢迎页 —— 图形点击「继续」；终端显示欢迎文字后自动开始环境检查；
   2. 环境检查 —— 自动完成，逐项显示 ✅/❌，并以 ℹ️ 行显示“首次安装/升级安装”等检测结果；全部 ✅ 才会继续；
   3. 安装位置 —— 直接回车使用默认 `/opt/material_matcher`；
   4. 数据位置 —— 向导展示服务器磁盘前三名及剩余空间并推荐最大者：输入 y 接受推荐（数据自动放在该磁盘并经 /var/lib/material_matcher 统一访问）；输入 n 改选编号或自定义路径；该选择决定数据库/上传/结果的落盘位置，首次安装后固定不变；
   5. 服务端口 —— 默认 18080；被占用时向导会提示并允许改选；
   6. 管理员密码 —— y 手工输入（至少 10 位、需含字母和数字、不回显）或 n 自动生成；自动生成的密码在交互终端会显示一次，请务必保存。出于安全，若安装输出被重定向到日志/管道（非交互终端），密码不会显示在屏幕上，只写入 root-only 文件 `/etc/material_matcher/secret/admin_password.env`；
   7. 确认安装 —— 核对版本、目录、端口后点击「继续」（终端输入 y）；
   8. 安装进度 —— 每个阶段都有文字提示（校验介质、复制程序、安装模型、环境诊断、启动服务、验证就绪、导入默认业务数据等）。根据服务器与存储速度，实测从不到 1 分钟（缓存充足的新服务器）到约 10 分钟（机械盘老服务器）均属正常，请勿关闭窗口。
4. 看到【安装成功】页面后，按页面提示在浏览器打开地址（例如 `http://192.168.x.x:18080`），用 `admin` 和刚才的密码登录；出于安全，系统会要求首次登录设置新的登录密码，请按界面提示完成。安装完成后系统已自动预置 **6 个正式匹配方案（A001 元器件 / A002 标准紧固件 / A003 金属材料 / A005 非金属材料 / A006 复合材料 / A007 物资类其他(跨类目)）与默认同义词配置**，无需任何手工导入。
5. 最小验收（必须全部完成才算安装成功）：
   1. 登录成功；
   2. “系统设置 · 关于”中的版本号与介质 BUILD_INFO.txt 一致；
   3. “匹配方案”列表能看到上述 6 个方案且每个都能正常打开；“同义词配置”能看到默认规则与版本；
   4. 进入第一步 · 数据上传，分别上传安装介质 `smoke/` 目录中的《smoke-待匹配数据.xlsx》（待匹配数据）与《smoke-集团标准数据.xlsx》（集团标准数据），选择任意现有匹配方案启动匹配；
   5. 第二步能看到进度；第三步能打开结果；第四步能导出结果 Excel；
   6. 重启服务器后服务自动恢复（通常几秒至 1 分钟内自动恢复，重新打开页面确认即可）。


## 日常运维（一键脚本，均在介质 02-非Docker方式 目录内）

| 想做的事 | 执行 | 效果 |
|---|---|---|
| 重启系统服务（配置/代码变更后） | `sudo ./重启服务.sh` | 重启并确认可访问，最长等 60 秒 |
| 临时停用（保留一切） | `sudo ./停用服务.sh` | 停止服务并取消开机自启；数据、程序、配置全部保留 |
| 恢复运行 | `sudo ./重启服务.sh` | 重新启用并启动 |
| 开启每日自动备份 | `sudo ./定时备份.sh enable 02:30` | 每天 02:30 自动备份到 /var/backups/material_matcher（root-only，保留最近 14 份）；`list` 查看、`run` 立即备份、`disable` 关闭 |
| 卸载本系统（**不动 Docker/系统其它软件**） | `sudo ./卸载服务.sh` | 删除 systemd 单元与 /opt/material_matcher；**默认保留全部业务数据与配置**，重装即用 |
| 卸载并清除数据（不可恢复） | `sudo ./卸载服务.sh --purge-data` | 两次输入 yes 确认后删除数据与配置 |

## 安装失败时

- 页面会给出中文原因和处理建议（例如端口占用、介质不完整、磁盘不足）；
- 安装报告保存在 `/var/log/material_matcher/install-reports/`；向导技术日志在 `/var/tmp/material_matcher_wizard-*.log`（root 可读）；
- 将「维护工具 → 导出诊断包」生成的文件发给原厂，无需自行猜测修复。

## 安全说明

- 安装程序不修改防火墙规则；若局域网无法访问，请网络管理员放行所用端口；
- 管理员密码文件仅 root 可读：`/etc/material_matcher/secret/admin_password.env`；
- 诊断包不包含密码、会话与客户文件。
