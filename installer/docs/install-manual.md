# 物料集团码智能匹配平台 · 银河麒麟 V10 安装手册

本手册面向没有开发背景的系统管理员。全程离线，无需联网。

## 你需要准备

- 一台银河麒麟 Linux V10 服务器（x86_64 或 aarch64，与介质标注一致）；
- 管理员（root 或 sudo）权限；
- 至少 6 GB 可用磁盘空间；
- 完整复制到本地磁盘的安装介质目录（不要直接从 U 盘安装）。

## 安装步骤

1. 复制安装目录到服务器，例如 `/home/admin/物料集团码智能匹配平台安装包/`。
2. 启动安装：
   - 图形桌面：双击「安装物料集团码智能匹配平台」；若系统禁止直接运行，右键目录空白处打开终端，执行 `./启动安装.sh`。
   - 无图形界面：在终端执行 `./启动安装.sh`。
3. 按向导提示操作，向导依次为：
   1. 欢迎页 —— 点击「继续」；
   2. 环境检查 —— 自动完成，逐项显示 ✅/❌；全部 ✅ 才会继续；
   3. 安装位置 —— 直接回车使用默认 `/opt/material_matcher`；
   4. 数据位置 —— 推荐选择「自动选择」；仅高级用户手工指定；
   5. 服务端口 —— 默认 18080；被占用时向导会提示并允许改选；
   6. 管理员密码 —— 手工输入（至少 8 位、不回显）或选择自动生成；自动生成时安装完成页会显示一次，请务必保存；
   7. 确认安装 —— 核对版本、目录、端口后点击「继续」；
   8. 安装进度 —— 每个阶段都有文字提示（校验介质、复制程序、安装模型、环境诊断、启动服务、验证就绪等）。根据服务器性能通常需要 3～10 分钟，请勿关闭窗口。
4. 看到【安装成功】页面后，按页面提示在浏览器打开地址（例如 `http://192.168.x.x:18080`），用 `admin` 和刚才的密码登录。
5. 最小验收（必须全部完成才算安装成功）：
   1. 登录成功；
   2. 「系统设置 · 关于」中的版本号与介质 BUILD_INFO.txt 一致；
   3. 进入第一步 · 数据上传，上传介质 `smoke/` 目录中的《最小测试数据.xlsx》，选择任意现有匹配方案启动匹配；
   4. 第二步能看到进度；第三步能打开结果；第四步能导出结果 Excel；
   5. 重启服务器后服务自动恢复（等待约 1 分钟后重新打开页面确认）。

## 安装失败时

- 页面会给出中文原因和处理建议（例如端口占用、介质不完整、磁盘不足）；
- 技术细节在日志：安装向导结束时会显示日志路径（默认 `/var/tmp/material_matcher_wizard-*.log`）；
- 将「维护工具 → 导出诊断包」生成的文件发给原厂，无需自行猜测修复。

## 安全说明

- 安装程序不修改防火墙规则；若局域网无法访问，请网络管理员放行所用端口；
- 管理员密码文件仅 root 可读：`/etc/material_matcher/secret/admin_password.env`；
- 诊断包不包含密码、会话与客户文件。
