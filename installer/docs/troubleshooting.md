# 物料集团码智能匹配平台 · 常见故障处理（面向安装/运维人员）

| 现象 | 你会看到的提示 | 你该怎么做 |
|---|---|---|
| 操作系统不是银河麒麟 V10 | “当前安装包只支持银河麒麟 Linux V10” | 停止安装，向交付人员索取匹配系统的介质 |
| CPU 架构不符 | 环境检查“CPU 架构 ❌” | 换用 x86_64 / aarch64 对应介质 |
| 介质损坏/文件缺失 | “安装介质校验失败…请重新复制” | 从源头重新完整复制介质后重试 |
| 磁盘不足 | “磁盘空间不足：需要至少 XXX MB” | 清理磁盘或换更大磁盘 |
| 端口被占用 | “端口 18080 已被占用…” | 在向导提示后输入新端口（向导会给出建议值） |
| 权限不足 | “当前账号没有安装权限…” | 使用 root 或管理员账号重新运行 |
| 两份数据库 | “检测到两份业务数据库…拒绝自动选择” | 立即停止！导出诊断包联系原厂，切勿手工删除任何 .db 文件 |
| 新版本诊断失败 | “部署前诊断失败…旧版本保持不变” | 旧系统不受影响；导出诊断包联系原厂 |
| 启动/就绪失败 | “已自动回滚到安装前状态” | 确认旧系统页面仍可打开；导出诊断包联系原厂 |
| 浏览器打不开 | —— | 先 `mmctl status` 看服务是否 active；若正常，请网络管理员确认防火墙已放行端口 |
| 忘记 admin 密码 | —— | 以 root 查看 `/etc/material_matcher/secret/admin_password.env`（仅管理员） |

## 导出诊断包

维护菜单 → “导出诊断包”，生成 `/var/tmp/mm-diagnostics-*.tar.gz`，把它发给原厂。
诊断包只包含状态、有限日志、健康检查和版本信息，不含密码、会话与客户数据。
